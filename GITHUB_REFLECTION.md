### Question 1: Git Fetch vs. Git Pull
`git fetch` downloads all commits, files, and refs from a remote repository without altering local working branches. In contrast, `git pull` combines `git fetch` and `git merge` in a single command, updating the current local branch with changes from remote.

---

### Question 2: Pull Requests & Code Review
A Pull Request (PR) proposes changes from a feature branch to a target branch like `main`. Code reviews allow team members to inspect, test, and discuss code quality before merging, preventing bugs and enforcing architectural consistency.

---

### Question 3: Branching Strategy in Teams
Feature branching isolates active development on separate branches. This enables multiple developers to build features concurrently without overwriting code or breaking the stable production code on `main`.
